# Kittygram

**Kittygram** — это социальная сеть для обмена фотографиями любимых питомцев. Проект позволяет регистрироваться, добавлять своих котиков, редактировать их профили и смотреть котиков других пользователей.

## Стек технологий:
- **Backend:** Python 3.12, Django 5.1, Django REST Framework, PostgreSQL, Gunicorn.
- **Frontend:** React, Node.js.
- **Инфраструктура:** Docker, Docker Compose, Nginx.
- **CI/CD:** GitHub Actions.
